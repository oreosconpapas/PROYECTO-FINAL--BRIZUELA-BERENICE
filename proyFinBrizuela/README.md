# 🐾 ANIMALIA — Enciclopedia Web de Animales

Aplicación web educativa desarrollada como **Proyecto Final Integrador** para la materia **Web 2 (2026)** del **CET N° 30**.

## Descripción del proyecto

**ANIMALIA** es una plataforma de divulgación sobre la biodiversidad del planeta. Permite explorar distintas clasificaciones de especies animales, conocer los principales hábitats naturales y concientizar sobre la importancia de la conservación ambiental.

## Tecnologías utilizadas

* **Angular 21** (Componentes Standalone, Control Flow `@if` / `@else` / `@for`, Routing)
* **TypeScript** (Interfaces y tipado de datos)
* **Bootstrap 5** (Diseño responsivo y componentes visuales)
* **HTML5 y CSS3**

## Secciones de la aplicación

* **Inicio:** Presentación general de la plataforma.
* **Especies (Productos):** Catálogo interactivo de grupos animales utilizando un componente reutilizable (`ProductoCard`) con comunicación padre-hijo mediante `@Input()` y `@Output()`.
* **Hábitats:** Recorrido por 8 ecosistemas naturales y su fauna característica.
* **Conservación:** Información sobre la protección de la biodiversidad y estrategias ambientales.
* **Nosotros:** Identidad, propósito y pilares educativos del proyecto.
* **Contacto:** Formulario de consulta e información de ubicación.
* **Página 404 (Not Found):** Manejo de rutas inexistentes.

## Cómo ejecutar el proyecto localmente

1. Clonar este repositorio.
2. Instalar las dependencias ejecutando `npm install` en la terminal.
3. Iniciar el servidor de desarrollo con `ng serve`.
4. Abrir el navegador en `http://localhost:4200/`.
